Software Index — Bhabhi Card Game: Multiplayer

Last updated: 6 September 2026 · Applies to build 1.0.3 (16) and later

This page is the index of games and software in Bhabhi Card Game: Multiplayer (Apple ID 6803359801, bundle identifier com.logicstack.bhabi), published by Logicstack LLC. It is maintained for App Store Review Guideline 4.7 and is linked from the App Review Information notes of every submission.

Index of non-embedded games and software

0 entries. This app contains no games or software that are not embedded in the binary. There are no external titles, no third-party developers and no hosted content, so there are no names, developers or URLs to list.

None of the software this app offers is downloaded, interpreted, hot-patched, streamed or executed after review. Specifically, the submitted binary contains no HTML, JavaScript, WebAssembly, JS bundle, Lua or SWF files of our own; there is no emulator, no chatbot, no plug-in host and no mini app platform. The one exception is third-party advertising delivered by Google's SDK, described below. Online multiplayer runs the rules engine on the device and synchronises only serialized game state — card indices, turn order and timestamps. No screen, string, layout, rule or asset is fetched from a server.

Third-party content served by embedded SDKs

Two surfaces in the app render content produced by Google rather than by us. We list them here for completeness. Neither is a game or software that this app offers, and neither is ours to index.

  • Google AdMob advertising — Google LLC — https://admob.google.com/. Rewarded and occasional interstitial advertisements, served through the Google Mobile Ads SDK. Every request is made non-personalised, so creatives are chosen for this app rather than from a profile of the user, and the advertising identifier is never read. Creatives are selected and delivered by Google and can include interactive formats. They are third-party advertising, not software offered by this app.
  • Google User Messaging Platform consent form — Google LLC — https://support.google.com/admob/answer/10113207. Fetched and rendered by Google's SDK. No message is currently published for this app, so no form is shown; the component is listed because the SDK that renders it is still linked into the binary.

WebKit is linked into the binary only as a transitive dependency of the Google Mobile Ads SDK, which uses it to render the two surfaces above. No code we wrote uses it, and no content of ours is rendered as web content.
